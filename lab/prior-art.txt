One line a feature: the first commit on the main branch that holds it, with
that commit's author date in the author's time zone (+08:00). Each was found
by searching every path of the history for a marker of the feature (git log
-S or -G for a word in the code; git log --diff-filter=A for a file) and then
reading that commit's diff. So a word that only shares the feature's name
does not count: "shadow" first appears on 2020-12-07 in a comment about a
shadowed Rust variable, a month before shadow playing. Where a feature began
earlier under another name or in another form, the lines under it say so.
